# `0.10.0-SNAPSHOT`

Diese Datei beschreibt die unveröffentlichte Entwicklungszeile des nativen
`ilic`-Compilers. Sie ist kein Release- und kein Stabilitätsversprechen.

Die eingecheckte Basisversion lautet `0.10.0-SNAPSHOT`. Native C++-API, C-ABI,
CLI und Source-Manifeste verwenden diese Zeichenkette innerhalb der
Entwicklungszeile. Für ein verteilbares WASM/npm-Artefakt wird eine konkrete
Version mit UTC-Zeitstempel und optionaler numerischer Build-ID erzeugt, zum
Beispiel:

```text
0.10.0-SNAPSHOT.20260805143152.123456789
```

Der Ablauf bleibt bei der vorhandenen Paketierung:

```sh
ILIC_WASM_VERSION=0.10.0-SNAPSHOT.20260805143152.123456789 \
  ./scripts/build-wasm.sh
node scripts/prepare-npm-snapshot.mjs --timestamp 20260805143152 --build-id 123456789
node scripts/test-npm-packages.mjs \
  --expected-version 0.10.0-SNAPSHOT.20260805143152.123456789 \
  --version-kind snapshot
```

Die Source-Manifeste werden nicht verändert. Die Staging-Kopie erhält die
konkrete Version; die Paketprüfung schreibt das nachvollziehbare Manifest
`artifacts/compiler-wasm-snapshot.json` mit vollständigem Git-SHA und
SHA-256. Alle Pakete eines Laufs verwenden dieselbe Snapshot-ID.

Eine spätere Veröffentlichung verwendet ausschließlich den Dist-Tag
`snapshot`:

```sh
npm publish <tarball> --tag snapshot
```

Dieser Auftrag veröffentlicht nichts, erzeugt keine Tags und aktualisiert weder
`interlis-language-tools` noch `interlis-web-ide`. Ein finales `0.10.0` ist
ausdrücklich nicht Teil dieser Entwicklungszeile.
